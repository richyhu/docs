# 产品需求文档 (PRD) - AI 智能帮助文档系统

## 1. 产品概述

一款现代化的帮助文档网页系统，集成 AI 智能助手，为用户提供沉浸式的文档阅读与交互体验。AI 助手以侧边栏和浮动工具栏两种形式存在，能够基于当前页面内容进行智能问答和内容解释。

- 目标用户：需要查阅帮助文档的产品用户
- 核心价值：通过 AI 辅助降低文档理解门槛，提升信息获取效率

## 2. 核心功能

### 2.1 功能模块

1. **文档阅读页**：侧边导航 + 文档内容区 + AI 侧边栏
2. **AI 侧边栏**：常驻右侧，可展开/收起，自动读取当前页面内容作为上下文
3. **浮动 AI 工具栏**：选中文字后浮现，支持解释、翻译、总结等快捷操作
4. **首页**：文档分类入口 + 搜索 + 快速导航

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 首页 | Hero 区域 | 产品名称、简介、搜索框 |
| 首页 | 文档分类卡片 | 按主题分类的文档入口 |
| 文档阅读页 | 左侧导航栏 | 文档目录树，支持展开折叠 |
| 文档阅读页 | 文档内容区 | Markdown 渲染的文档内容 |
| 文档阅读页 | AI 侧边栏 | 聊天式交互，自动注入页面上下文 |
| 文档阅读页 | 浮动工具栏 | 选中文字后弹出，提供快捷 AI 操作 |
| 搜索页 | 搜索结果 | 全文搜索结果列表 |

## 3. 核心流程

用户打开文档 → 浏览左侧导航 → 阅读文档内容 → 遇到疑问时：
- 方式一：点击右侧 AI 侧边栏，输入问题获取解答
- 方式二：选中不理解的内容，浮动工具栏出现，点击"解释"等操作

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深靛蓝 (#1e1b4b) + 琥珀色点缀 (#f59e0b)，营造专业而温暖的阅读氛围
- **背景**：浅灰渐变底色，文档区白色卡片，层次分明
- **字体**：正文使用 "Noto Sans SC"，标题使用 "Space Grotesk"，兼顾中文可读性与现代感
- **布局**：三栏布局（导航 | 内容 | AI），响应式适配
- **圆角**：大圆角 (12px-16px)，柔和现代
- **动效**：侧边栏滑入/滑出，浮动工具栏淡入，内容区平滑滚动

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 首页 | Hero 区域 | 渐变背景，大标题，搜索框带图标 |
| 首页 | 文档分类卡片 | 圆角卡片，图标+标题+描述，hover 上浮阴影 |
| 文档阅读页 | 左侧导航栏 | 固定定位，树形目录，活跃项高亮 |
| 文档阅读页 | 文档内容区 | 白色卡片，Markdown 排版，代码高亮 |
| 文档阅读页 | AI 侧边栏 | 右侧滑入面板，聊天气泡，输入框 |
| 文档阅读页 | 浮动工具栏 | 选中文字上方浮现，圆角按钮组 |

### 4.3 响应式设计

- 桌面端（≥1280px）：三栏完整展示
- 平板端（768px-1279px）：导航栏折叠为汉堡菜单，AI 侧边栏覆盖式
- 移动端（<768px）：单栏布局，AI 通过底部浮动按钮触发

## 5. AI 功能详细设计

### 5.1 AI 侧边栏

- 默认收起状态，显示为右侧窄条带 AI 图标
- 点击展开为完整聊天面板（约 380px 宽）
- 自动将当前页面文档内容作为系统提示注入
- 支持多轮对话，保留对话历史
- 支持清除对话、重新开始

### 5.2 浮动 AI 工具栏

- 用户选中文字后，在选区上方浮现工具栏
- 提供快捷操作按钮：解释、翻译、总结、提问
- 点击操作后，自动在侧边栏中打开并展示结果
- 选区消失或点击空白处时工具栏自动隐藏

### 5.3 AI 接口

- 使用 OpenRouter API
- 模型：glm-4.5-air:free
- 流式输出，实时显示 AI 回复
